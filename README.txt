MXSN Nexus v1
===============
هذه نسخة أولية قابلة للعرض والتطوير.

التشغيل:
- افتح index.html في المتصفح لعرض المتجر.
- افتح admin.html لإدارة المنتجات محليًا من نفس المتصفح.

مهم:
هذه النسخة لا تحتوي بعد على قاعدة بيانات أو تسجيل دخول آمن أو بوابة دفع حقيقية.
المرحلة التالية هي نقل المنتجات والإدارة إلى Backend/Database، ثم ربط بوابة دفع مناسبة، ثم نشر الموقع على استضافة عامة.
لا تضع بيانات بطاقات أو مفاتيح سرية داخل JavaScript أو HTML.
